## 💻 Sobre o Projeto
O **GameVerse** foi criado com o objetivo de aplicar conceitos iniciais de:
* Estruturação semântica em HTML.
* Estilização com CSS.

## 🛠️ Como rodar o projeto
Para visualizar o projeto localmente:
1. Clone o repositório: `git clone https://github.com/Gu1bas/GameVerse.git`
2. Abra o arquivo `index.html` no seu navegador.
